## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| parsed puzzle description -> DOM render path | sanitized rich text enters visible play metadata |
| rendered link elements -> user interaction | link attributes/protocols may be abused if unsafely preserved |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04 | XSS (Elevation/Tampering) | `renderToDom` description insertion | mitigate | Render only sanitizer output; never inject raw authored HTML and suppress empty-stripped content |
| T-09-05 | S (Spoofing) | link presentation in description block | mitigate | Constrain link attributes/protocols via sanitizer contract and assert via UI security tests |
| T-09-06 | D (Denial of Service) | malformed description content | mitigate | Fail-soft render path that skips description block instead of throwing or blocking play flow |
</threat_model>
