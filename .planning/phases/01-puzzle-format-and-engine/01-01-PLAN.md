Coordinate helpers (src/puzzles/loader.js):
```javascript
export const posKey = (col, row) => `${col},${row}`   // "col,row" key for board Map
export const parseKey = (key) => key.split(',').map(Number)  // "col,row" -> [col, row]
```

Cell type (JSDoc — used throughout engine):
```javascript
/** @typedef {{ piece: Piece | null, isGoal: boolean }} Cell */
/** @typedef {{ type: string, color: 'white' | 'black', direction?: [number, number] }} Piece */
// type: 'p'|'n'|'b'|'r'|'q'|'k'
// color: 'white' (lowercase char) | 'black' (uppercase char)  [D-03, D-04]
// direction: ONLY present on pawns — [dc, dr] e.g. [0,-1]=up, [0,1]=down, [1,0]=right, [-1,0]=left
```

Board type:
```javascript
// Map<string, Cell>  keyed by "col,row"  [D-10]
// Impassable squares (x) are ABSENT from the Map  [D-11]
// !board.has(key) means "cannot enter" for ALL piece types — no separate isImpassable flag
```

Puzzle runtime object (returned by parsePuzzle):
```javascript
{
  id: string,           // stable 8-char alphanumeric  [FMT-04]
  schemaVersion: 1,     // integer  [FMT-05]
  title: string,
  goalType: 'capture-all-targets' | 'reach-all-goal-squares',   // [FMT-03]
  targetColor: 'white' | 'black' | null,  // required when goalType === 'capture-all-targets'
  board: Map<string, Cell>,
  width: number,
  height: number,
}
```

Raw catalogue entry shape (input to parsePuzzle):
```javascript
{
  schemaVersion: 1,
  id: 'xk3m9pq2',               // stable, hand-assigned, never auto-incremented
  title: 'Corner Trap',
  goalType: 'capture-all-targets',
  targetColor: 'black',
  grid: ['x-P', '-p-', 'n-x'],  // each string = one row; x=impassable, -=empty, G=goal
  pawnDirections: {              // keyed by "col,row" — only needed when pawns are present
    '1,1': [0, -1],
  },
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| catalogue.js → parsePuzzle | Raw puzzle object crosses into runtime representation; malformed entries could throw uncaught errors or produce corrupt board state |
| engine input | In Phase 1 all inputs are static JS objects authored by the developer — no user input, no network data. Trust boundary is effectively internal. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | parsePuzzle input | accept | Phase 1 catalogue entries are static, developer-authored JS modules — no external input. Schema version check (`schemaVersion !== 1 → throw`) catches version drift at parse time. |
| T-01-02 | Information Disclosure | puzzle IDs in catalogue.js | accept | IDs are opaque strings embedded in source; no PII, no secrets. Source is public game content. |
| T-01-03 | Denial of Service | malformed grid (null/undefined row) | mitigate | parsePuzzle must guard against rows that are not strings: `if (typeof rowStr !== 'string') return` before the `[...rowStr].forEach`. Catalogue test verifies valid structure. |
| T-01-04 | Tampering | pawnDirections key collision | accept | Duplicate IDs detected by catalogue.test.js at CI time. Risk is puzzle-design error, not security issue. |
</threat_model>
