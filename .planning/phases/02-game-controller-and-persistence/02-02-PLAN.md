Sequential unlock rule (NAV-02):
  - puzzle at index 0 is ALWAYS unlocked
  - puzzle at index i is unlocked iff catalogue[i-1].id is in solvedIds
  - Solving puzzle[i] unlocks puzzle[i+1] — no gaps, no skipping

Position string (NAV-03):
  - "current / total" where current = 1-based index of the active puzzle in catalogue
  - Example: active puzzle is index 6, catalogue has 42 entries -> "7 / 42"

Puzzle list entry shape returned by getPuzzleList:
  { id: string, title: string, status: 'unlocked' | 'solved' | 'locked' }
  - 'solved': id is in solvedIds
  - 'unlocked': unlocked (per rule above) but NOT in solvedIds
  - 'locked': not yet unlocked

NAV-05 (ordering): catalogue array order IS the display order. nav.js preserves it.

<feature>
  <name>Catalogue Navigation Helpers</name>
  <files>src/puzzles/nav.js, src/puzzles/nav.test.js</files>
  <behavior>
    Pure function API (all accept solvedIds as Set<string> or string[]; internally convert to Set):

    getUnlockedIds(solvedIds):
    - Returns string[] of all currently unlocked puzzle IDs
    - Index 0 is always included
    - Index i is included iff catalogue[i-1].id is in solvedIds
    - If ALL puzzles are solved, returns all IDs

    isUnlocked(puzzleId, solvedIds):
    - Returns boolean — true iff puzzleId appears in getUnlockedIds result
    - Returns false for unknown IDs not in catalogue

    getPuzzlePosition(puzzleId):
    - Returns string "N / M" where N = 1-based index+1 of puzzleId in catalogue, M = catalogue.length
    - Returns null if puzzleId not found in catalogue

    getPuzzleList(solvedIds):
    - Returns catalogue.map entry with status field
    - Status: 'solved' if id in solvedIds, 'unlocked' if unlocked but not solved, 'locked' otherwise
    - Preserves catalogue order (NAV-05)

    Write as Vitest tests FIRST (RED gate). Use a local mock catalogue in tests — do NOT import the real catalogue file in tests (keeps tests hermetic and fast). Instead, inject catalogue as a parameter or use vi.mock.

    Recommended approach: nav.js functions accept an optional catalogue parameter defaulting to the imported catalogue. Tests pass a controlled 3-5 puzzle mock array directly.

    Test cases to write (all must FAIL before nav.js exists):

    Group "getUnlockedIds":
    - With empty solvedIds: returns only first puzzle id
    - With first puzzle solved: returns first two ids
    - With first two solved: returns first three ids
    - With all solved: returns all ids
    - Empty catalogue: returns []

    Group "isUnlocked":
    - First puzzle is unlocked even with empty solvedIds
    - Second puzzle is locked with empty solvedIds
    - Second puzzle is unlocked after first is solved
    - Unknown id returns false

    Group "getPuzzlePosition":
    - First puzzle: "1 / N"
    - Last puzzle: "N / N"
    - Returns null for unknown id

    Group "getPuzzleList":
    - Entry for solved puzzle has status 'solved'
    - Entry for unlocked-but-unsolved puzzle has status 'unlocked'
    - Entry for locked puzzle has status 'locked'
    - All entries have id and title fields
    - Order matches catalogue order
  </behavior>
  <implementation>
    After all tests are RED:

    Import catalogue default:
    ```js
    import _catalogue from './catalogue.js'
    ```

    Each function accepts an optional last parameter `catalogue = _catalogue` for test injection.

    getUnlockedIds(solvedIds, catalogue = _catalogue):
    - const solved = new Set(solvedIds)
    - return catalogue.filter((entry, i) => i === 0 || solved.has(catalogue[i-1].id)).map(e => e.id)

    isUnlocked(puzzleId, solvedIds, catalogue = _catalogue):
    - return getUnlockedIds(solvedIds, catalogue).includes(puzzleId)

    getPuzzlePosition(puzzleId, catalogue = _catalogue):
    - const idx = catalogue.findIndex(e => e.id === puzzleId)
    - return idx === -1 ? null : `${idx + 1} / ${catalogue.length}`

    getPuzzleList(solvedIds, catalogue = _catalogue):
    - const solved = new Set(solvedIds)
    - const unlocked = new Set(getUnlockedIds(solvedIds, catalogue))
    - return catalogue.map(e => ({
        id: e.id,
        title: e.title,
        status: solved.has(e.id) ? 'solved' : unlocked.has(e.id) ? 'unlocked' : 'locked'
      }))

    Export named: { getUnlockedIds, isUnlocked, getPuzzlePosition, getPuzzleList }
  </implementation>
</feature>
