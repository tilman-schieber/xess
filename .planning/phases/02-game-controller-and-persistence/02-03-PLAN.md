<feature>
  <name>Game Controller</name>
  <files>src/controller.js, src/controller.test.js</files>
  <behavior>
    createController() returns a controller object with mutable internal state.

    Internal state:
    ```
    {
      puzzle: null,          -- parsed puzzle object (includes id, goalType, targetColor, board)
      board: null,           -- current board Map (mutable pointer; each move creates new Map via applyMove)
      undoStack: [],         -- array of board Maps (pre-move snapshots; ENG-08 pattern)
      solvedIds: [],         -- array of solved puzzle IDs (loaded from store on init)
      won: false,            -- true after a winning move until next loadPuzzle
    }
    ```

    Methods:

    loadPuzzle(puzzleId):
    - Finds raw entry in catalogue by id; throws if not found
    - Calls parsePuzzle(rawEntry) to get parsed puzzle + initial board
    - Loads store via loadStore()
    - If store.activeState exists AND store.activeState.puzzleId === puzzleId:
        Re-hydrate: board = new Map(store.activeState.boardEntries)
                    undoStack = store.activeState.undoEntries.map(e => new Map(e))
    - Else: board = parsedPuzzle.board, undoStack = []
    - Sets state.puzzle = parsedPuzzle, state.board, state.undoStack
    - Sets state.solvedIds = store.solvedIds (array)
    - Sets state.won = false
    - Returns { puzzle, board, undoStack, solvedIds, won: false }

    selectPiece(posKey):
    - If no puzzle loaded: return []
    - If board cell at posKey has no piece, or piece is not player color ('white'): return []
    - Returns getLegalMoves(state.board, posKey)

    makeMove(from, to):
    - Validates: state.puzzle loaded, state.won === false
    - Validates: to is in getLegalMoves(state.board, from) — if not, return { error: 'illegal_move' }
    - const prev = state.board
    - const { board: next, won } = applyMove(state.board, from, to, state.puzzle)
    - state.undoStack.push(prev)
    - state.board = next
    - state.won = won
    - saveActiveState(state.puzzle.id, state.board, state.undoStack)  -- debounced
    - If won:
        state.solvedIds = [...new Set([...state.solvedIds, state.puzzle.id])]
        saveProgress(state.solvedIds)
        clearActiveState()
    - Returns { board: state.board, won, captured }

    undo():
    - If undoStack is empty: return { board: state.board, undoStack: [] } (no-op)
    - state.board = state.undoStack.pop()
    - state.won = false
    - saveActiveState(state.puzzle.id, state.board, state.undoStack)
    - Returns { board: state.board, undoStack: state.undoStack }

    reset():
    - Re-parses puzzle from raw catalogue entry to get fresh initial board
    - state.board = freshParsed.board
    - state.undoStack = []
    - state.won = false
    - clearActiveState()
    - Returns { board: state.board }

    getPuzzleList():
    - Returns getPuzzleList(state.solvedIds) from nav.js

    getPuzzlePosition(puzzleId):
    - Returns getPuzzlePosition(puzzleId) from nav.js

    isUnlocked(puzzleId):
    - Returns isUnlocked(puzzleId, state.solvedIds) from nav.js

    Write as Vitest tests FIRST (RED gate). Mock store.js and nav.js with vi.mock to isolate controller logic. Use real parsePuzzle + a small inline catalogue fixture for board operations (avoids mocking the engine).

    Test cases to write (all must FAIL before controller.js exists):

    Group "loadPuzzle":
    - Fresh load: puzzle, board, undoStack=[]; solvedIds from store
    - Re-hydrate: if store has activeState for puzzleId, board and undoStack are restored
    - Different puzzleId in store: starts fresh (not re-hydrated)
    - Unknown puzzleId throws

    Group "selectPiece":
    - Valid player piece returns non-empty legal moves array
    - Empty square returns []
    - Opponent piece returns []
    - Before loadPuzzle returns []

    Group "makeMove":
    - Legal move: board updates, undoStack grows by 1, returns { won: false }
    - Illegal move: returns { error: 'illegal_move' }, board unchanged, stack unchanged
    - Winning move: won=true, saveProgress called with new solvedId, clearActiveState called
    - Cannot move after won=true: returns error

    Group "undo":
    - After one move: board restores, undoStack shrinks by 1
    - On empty stack: returns current board, no change (no-op)
    - After undo, won resets to false

    Group "reset":
    - Board restores to initial state, undoStack is [], clearActiveState called
    - solvedIds unchanged after reset

    Group "getPuzzleList / getPuzzlePosition / isUnlocked":
    - Delegates to nav.js with current solvedIds (verified via vi.mock return value)

    ```js
    // src/controller.js
    import { getLegalMoves, applyMove } from './engine/index.js'
    import { parsePuzzle } from './puzzles/loader.js'
    import catalogue from './puzzles/catalogue.js'
    import { loadStore, saveProgress, saveActiveState, clearActiveState } from './store/store.js'
    import { isUnlocked, getPuzzlePosition, getPuzzleList } from './puzzles/nav.js'

    export function createController() {
      const state = {
        puzzle: null,
        board: null,
        undoStack: [],
        solvedIds: [],
        won: false,
      }

      function _rawEntry(puzzleId) {
        const raw = catalogue.find(e => e.id === puzzleId)
        if (!raw) throw new Error(`Unknown puzzle id: ${puzzleId}`)
        return raw
      }

      return {
        loadPuzzle(puzzleId) { ... },
        selectPiece(posKey) { ... },
        makeMove(from, to) { ... },
        undo() { ... },
        reset() { ... },
        getPuzzleList() { return getPuzzleList(state.solvedIds) },
        getPuzzlePosition(puzzleId) { return getPuzzlePosition(puzzleId) },
        isUnlocked(puzzleId) { return isUnlocked(puzzleId, state.solvedIds) },
      }
    }
    ```

    Player color convention: 'white' pieces are player-controlled (lowercase in catalogue grid). Opponent pieces are 'black' (uppercase). selectPiece filters by piece.color === 'white'.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| makeMove(from, to) call | Caller provides posKeys — must validate against getLegalMoves before applyMove |
| loadPuzzle(puzzleId) | Caller provides puzzleId — validate against catalogue before accessing |
| store re-hydration | Entries from localStorage (raw arrays) — re-hydrate with new Map(), not eval() |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Tampering | makeMove illegal destination | mitigate | validate `to` against getLegalMoves(board, from) before calling applyMove; return { error: 'illegal_move' } on mismatch |
| T-02-09 | Tampering | loadPuzzle with unknown id | mitigate | catalogue.find() returns undefined → throw Error('Unknown puzzle id') before parsePuzzle |
| T-02-10 | Tampering | store re-hydration with malformed entries | mitigate | new Map(boardEntries) with non-array input throws; wrap re-hydration in try/catch → fall back to fresh puzzle start |
| T-02-11 | Denial of Service | calling makeMove after won=true | mitigate | guard: if state.won return { error: 'game_over' } before any mutation |
| T-02-12 | Elevation of Privilege | selectPiece on opponent piece | mitigate | check piece.color === 'white' before returning legal moves; opponent pieces return [] |
</threat_model>
