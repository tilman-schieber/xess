<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| static track metadata -> nav/runtime helpers | malformed or stale authored references enter runtime selection logic |
| puzzle catalogue IDs -> launch routing | invalid IDs could break puzzle launch if not filtered |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | T (Tampering) | `src/puzzles/tracks.js` references | mitigate | Validate/normalize track membership against catalogue IDs and drop invalid references before nav consumption |
| T-08-02 | D (Denial of Service) | `getTrackPuzzleList` / `getTrackLaunchPuzzleId` | mitigate | Preserve fail-soft `[]`/`null` paths for unknown/empty/invalid tracks and never throw in user path |
| T-08-03 | I (Information Disclosure) | warning surface for integrity issues | accept | Limit warnings to non-sensitive static IDs/titles from bundled assets; no user data included |
</threat_model>
